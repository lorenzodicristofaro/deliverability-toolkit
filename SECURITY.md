# Security policy

## Supported versions
Only the latest release on `main` receives security fixes.

## Reporting a vulnerability
Please report vulnerabilities through GitHub private vulnerability reporting: open the repository's **Security**
tab and choose **Report a vulnerability**. Do not report vulnerabilities in public issues, pull requests or
discussions.

Include what you found, the steps to reproduce it and the version or commit you tested. Do not include real
customer data, credentials or other people's personal data in the report.
